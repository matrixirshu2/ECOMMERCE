# ECOMMERCE

Modern full-stack e-commerce store starter built with Next.js, React and TypeScript.

## Current version

- Responsive storefront homepage
- Product search UI
- Categories section
- Featured products
- Cart/wishlist UI placeholders
- Responsive mobile layout
- TypeScript + Next.js foundation

## Planned modules

- Customer authentication
- Product database and inventory
- Real cart and wishlist
- Checkout and payment gateway
- Customer order history and tracking
- Admin dashboard
- Product CRUD and bulk upload
- Categories, coupons and promotions
- Image storage
- Order management
- Analytics

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
